# Portfolio Site
A personal portfolio website engineered with a heavy focus on HTML5 semantic tags, ensuring superior web accessibility, clean document structure and strong SEO.
## ✨ Features
**Semantic Structure:** Utilizes modern HTML5 elements like header, nav, main, section, and footer to build a clean and meaningful document hierarchy.

**Custom CSS Cursor Component:** Features a hands-on styling component showcasing practical applications of various CSS cursor properties—such as `pointer`, `cross`, `grab`, `crosshair`, `text`, `vertical-text`, `progress`, `all-scroll`, `wait` and using custom images as cursors—to refine interactive user feedback.

**Web Accessibility & SEO:** Implements best practices for screen readers, keyboard navigation, and search engine crawlers to maximize discoverability and inclusivity.
